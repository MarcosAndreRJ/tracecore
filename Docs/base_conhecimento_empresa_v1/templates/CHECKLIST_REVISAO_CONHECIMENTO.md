# Checklist — Revisão de conhecimento

- [ ] Título descreve o problema/solução sem ambiguidade.
- [ ] Sintomas estão claros.
- [ ] Há indicação de quando NÃO se aplica.
- [ ] Produto/componente/versões estão corretos.
- [ ] Pré-condições foram registradas.
- [ ] Passos têm ordem e objetivo.
- [ ] Riscos estão destacados.
- [ ] Existe rollback quando aplicável.
- [ ] Existe validação pós-solução.
- [ ] Não há senha/token/segredo.
- [ ] Dados específicos do cliente foram sanitizados quando necessário.
- [ ] Casos de origem/validação estão vinculados.
- [ ] Proprietário está definido.
- [ ] Próxima revisão está definida.
